# 📊 Simple Sales Dashboard Design

## 🎯 Objective
To create a basic interactive dashboard to visualize **sales performance by product category, region, and month** using Power BI.

---

## 🧰 Tools Used
- **Power BI** – for dashboard creation and data visualization
---

## 📁 Dataset
**File Used:** `Superstore_Sales.csv`  

---

## ✅ Tasks Performed

1. **Imported the Dataset**
   - Loaded the `Superstore_Sales.csv` file into **Power BI Desktop**.

2. **Converted Order Date to Month-Year Format**
   - Extracted `Month` from the `Order Date` field using Power BI’s date functions for time-based visualizations.

3. **Created Visualizations**
   - 📈 **Line Chart**: Displayed **Sales over Months** to analyze monthly trends.
   - 📊 **Bar Chart**: Visualized **Sales by Region** to compare geographic performance.
   - 🍩 **Donut Chart**: Showed **Sales by Category** for understanding category-wise contribution.

4. **Added Interactivity with Filters**
   - Added **Slicer for Region** to enable users to filter data by geographic area.
   - Optionally included **Category Slicer** for deeper interactivity.

5. **Applied Visual Formatting**
   - Used meaningful **color coding** to highlight top-performing regions and categories.
   - Ensured charts were clean and readable with proper labels and legends.

6. **Generated Insights**
   - Wrote 3 key insights based on the dashboard findings (provided below).

---

## 📌 Key Insights

1. **Technology** category had the highest sales, contributing over **36%** of total sales.
2. The **West** region showed the highest performance in overall sales.
3. Sales peaked in **March and December**, indicating strong end-of-quarter demand.
4. The **South** region lagged behind, suggesting potential for market growth.
